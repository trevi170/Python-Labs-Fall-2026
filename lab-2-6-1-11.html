Task 1 - Understand the problem

Context

Your task: Given a starting time (hours and minutes) and an event duration (in minutes), calculate and print the end time.

Important constraints:

  • Hours must be in range 0-23 (24-hour format)
  • Minutes must be in range 0-59
  • Events can span across midnight (e.g., 23:50 + 30 min = 0:20)
  • Events can span multiple days (e.g., 10:00 + 2000 min = 11:20)

Key operators for this lab:

  • + : Addition (combine minutes)
  • // : Integer division (extract hours from minutes)
  • % : Modulo/remainder (keep values in valid ranges)

Hint: The modulo operator (%) is your key to handling time wrapping!
