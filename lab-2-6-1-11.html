In this lab, you'll calculate the end time of an event given the starting time and duration. You'll practice using the modulo (%) operator to handle time wrapping across hour and day boundaries.

✅ Upon completion, you will be able to:

  • Use the modulo (%) operator to find remainders and handle wrapping
  • Use integer division (//) to extract whole numbers from division
  • Work with multi-part data (hours and minutes)
  • Handle edge cases like midnight and 24-hour wrapping
  • Apply arithmetic operators to real-world problems
