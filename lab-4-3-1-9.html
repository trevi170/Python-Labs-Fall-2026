Lab Overview

In this lab, you'll write a reusable function that identifies prime numbers.

Objectives

Familiarize yourself with:

Scenario

A natural number is prime if it is greater than 1 and has no divisors other than 1 and itself.

For example, 8 is not a prime number because it can be divided evenly by 2 and 4. On the other hand, 7 is a prime number because no legal divisor divides it evenly.

Your task is to write a function checking whether a number is prime or not. The function is called is_prime, takes one argument, and returns True if the argument is prime or False otherwise.

Hint: try to divide the argument by subsequent values starting from 2. If the remainder is 0, the number cannot be prime.

Task 4 - Plan the prime check

Guide

Use a loop inside the function to try possible divisors. If any divisor divides evenly, return False. If the loop finishes without finding a divisor, return True.

def is_prime(num): # the for loop # the if statement return False return True

What each part does:

  • def is_prime(num): Creates a function that checks one number.
  • for i in range(2, int(1 + num ** 0.5)): Tests possible divisors starting at 2 and stopping near the square root.
  • num ** 0.5: Calculates the square root of num.
  • int(1 + num ** 0.5): Turns the stopping value into an integer and includes enough possible divisors.
  • if num % i == 0: Checks whether num divides evenly by i.
  • return False: Ends the function immediately if a divisor is found, because the number is not prime.
  • return True: Runs only after the loop finishes without finding any divisor.
  • if is_prime(i + 1): Calls the function for numbers from 2 through 20.

Why stop at the square root? If a number has a divisor larger than its square root, it also has a matching divisor smaller than its square root. That means checking past the square root would repeat work you do not need.

Square root reminder: In Python, num ** 0.5 gives the square root of num.
