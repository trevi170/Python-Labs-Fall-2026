Lab Overview

In this lab, you'll create a Python program that demonstrates fundamental programming concepts: user input, variable assignment, arithmetic operations, and output. You'll ask the user for two float numbers, then calculate and display their sum, difference, product, and quotient.

Learning Objectives

By the end of this lesson, you should be able to:

  • Create and assign values to variables in Python
  • Use input() and float() to collect decimal numbers from the user
  • Perform basic arithmetic operations (addition, subtraction, multiplication, division)
  • Display output using the print() function
  • Understand how Python handles numeric data types

Lesson Explanation

Master Python's input/output operations and basic arithmetic calculations. Write simple code to perform calculations and display results.

As you work, pay attention to the relationship between the code you type and the output Python displays. If you get an error, read the message as a clue: it usually points to the line or idea that needs attention.

Task 3 - Write your code

Code

Create a Python program with these 7 lines:

  • Line 1: Ask for the first value and convert it to a float.
  • Line 2: Ask for the second value and convert it to a float.
  • Line 3: Print the addition result.
  • Line 4: Print the subtraction result.
  • Line 5: Print the multiplication result.
  • Line 6: Print the division result.
  • Line 7: Print the final message.

Final code:

a = float(input("Enter first value: ")) b = float(input("Enter second value: ")) print("Addition:", a + b) print("Subtraction:", a - b) print("Multiplication:", a * b) print("Division:", a / b) print("\nThat's all, folks!")
Use the prompts exactly as shown. The values are entered by the user when the program runs.

Task 4 - Run your code

Testing

Execute your program, enter two numbers, and verify that every result prints to the console.

Example run: If you enter 10 and 2, your output should look like this:

Enter first value: 10 Enter second value: 2 Addition: 12.0 Subtraction: 8.0 Multiplication: 20.0 Division: 5.0 That's all, folks!

Your numbers may be different, so your results may be different. Your code is correct if the four operation labels and final message print without errors.

If you see an error: Check that both input lines use float(input(...)), and make sure variable names are spelled correctly. Python is case-sensitive.
