Lab Overview

In this lab, you'll practice the basics of Python lists: accessing an element by index, changing list content, printing a whole list, copying one element's value into another position, and checking the list length with len().

Learning Objectives

By the end of this lesson, you should be able to:

  • Create a list of values.
  • Access a single list element by index.
  • Modify list elements using assignment.
  • Print a list as a whole.
  • Use len() to check how many elements are in a list.

Lesson Explanation

Each element in a list can be accessed separately. For example, numbers[0] accesses the first element because Python list indexes start at 0.

A list can also be printed as a whole. Python displays the output with square brackets and commas, making it clear that the values belong to one list.

The length of a list may vary while a program runs. To check the current length, use len(list_name). The function returns the number of elements currently stored inside the list.

Task 1 - Understand list indexes

Context

Start with this list:

numbers = [10, 5, 7, 2, 1]

The first element is accessed with numbers[0], not numbers[1]. After changing numbers[0] to 111, this line would print 111:

print(numbers[0])

Key idea: List indexes count positions starting at 0. The fifth element is at index 4.

Task 3 - Write the list program

Code

Type the starter code exactly as shown:

numbers = [10, 5, 7, 2, 1] print("Original list content:", numbers) # Printing original list content. numbers[0] = 111 print("\nPrevious list content:", numbers) # Printing previous list content. numbers[1] = numbers[4] # Copying value of the fifth element to the second. print("Previous list content:", numbers) # Printing previous list content. print("\nList length:", len(numbers)) # Printing the list's length.

What the code does:

  • numbers = [10, 5, 7, 2, 1] creates the original list.
  • numbers[0] = 111 changes the first element.
  • numbers[1] = numbers[4] copies the fifth element's value into the second position.
  • print(numbers) displays the whole list.
  • len(numbers) returns the current number of elements in the list.
