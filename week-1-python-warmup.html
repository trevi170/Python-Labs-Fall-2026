WEEK 1

Week 1 Warm-Up: Code, Run, and Read Python

Python Warm-Up | Estimated time: 10-15 minutes | Difficulty: First week | Complete the tasks, attach screenshots, and generate your PDF.

Lab Overview

This short warm-up is for students who are just getting started. You will create a Python file, run it, read the console output, use a variable, and practice one tiny indented block.

Learning Objectives

By the end of this activity, you should be able to:

  • create and run a Python file in GitHub Codespaces;
  • use print() to display output;
  • store text in a variable;
  • recognize that indentation creates a block of code;
  • read simple error messages without panic.

Before You Start

Python follows your spacing carefully. A line that ends with a colon : usually starts a block. The lines inside that block are indented, usually four spaces.

Do not worry about memorizing everything today. The goal is to type a small program, run it, and connect what you wrote to what Python prints.

Where to Code

You will complete this activity using GitHub Codespaces, a free browser-based development environment that lets you write and run Python without installing anything.

  • Open GitHub Codespaces.
  • Sign in with your free GitHub account.
  • Create a new codespace and choose the Python template when prompted.
  • Create a file named week_1_warmup_first_last_name.py.
  • Run your file from the terminal and check the output.

Tasks

Complete each task in GitHub Codespaces. Attach screenshots only on tasks where you write, run, test, or show code output, then generate the PDF for Blackboard.

Task 1 - Make Python talk

Code

Type this code, then run the file:

print("Python is working.") print("This is my first week warm-up.")

Expected output:

Python is working. This is my first week warm-up.
Each print() statement creates one line of output.

Task 2 - Use a variable

Code

A variable stores a value so your program can use it later. Replace Alice with your own first name.

student_name = "Alice" print("Student name:") print(student_name)

Expected output example:

Student name: Alice

Notice: "Alice" has quotes because it is text. student_name does not have quotes because it is the variable name.

Task 3 - Practice one indented block

Indentation

Type this code exactly. The two lines after if ready: must be indented because they belong inside the if block.

ready = True if ready: print("I am inside the block.") print("Indented lines belong together.") print("I am outside the block.")

Expected output:

I am inside the block. Indented lines belong together. I am outside the block.

Block rule: The colon : starts the block. Four spaces show which lines are inside it. Moving back to the left ends the block.

Task 4 - Read one common error

Debugging

Now test what happens when indentation is missing. Type this broken version and run it:

ready = True if ready: print("This line should have been indented.")

Expected result: Python should show an IndentationError.

Fix it: Add four spaces before the final print() line, run the file again, and make sure the program works.
