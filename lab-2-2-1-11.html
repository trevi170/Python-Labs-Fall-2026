Task 1 - Understand escape sequences

Context

What are escape sequences? Special character combinations that have special meaning in strings.

Common escape sequences:

  • \n = newline (move to next line)
  • \t = tab (indent)
  • \" = double quote character
  • \' = single quote character
  • \\ = backslash character

Key concept: The backslash tells Python that the next character has special meaning.

  • Use \" to include double quotes in a string
  • Combine with \n for multiple lines

Example: Simple quote

Expected output:

Challenge: Multi-line with quotes

Expected output:

Use \" to escape double quotes. Each \" produces one quote in the output.
