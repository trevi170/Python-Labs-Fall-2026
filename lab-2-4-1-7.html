Task 1 - Understand variables

Context

What is a variable? A named container that stores a value.

Variable basics:

  • Variables have names (like john, total_apples)
  • Variables store values (numbers, text, etc.)
  • Use = to assign a value to a variable
  • You can use the variable later by referencing its name

Syntax: variable_name = value
