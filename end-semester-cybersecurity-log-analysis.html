Project Overview

In this final project, you will build a small defensive cybersecurity tool. Your program will scan a separate sample login log file, count failed login attempts, identify suspicious users, and print a short security report.

Scenario

You are helping a small company review a login log. The log contains successful and failed sign-in attempts. Your job is to write a Python script that scans the file and finds accounts that may need attention.

This is a defensive analysis project. You will not connect to any real system, attack anything, or use real personal data. You will only analyze the sample log file included in the assignment.

Task 2 - Read the log file with Python

File Input

Create your Python file. First, read the log file into a list named login_logs.

with open("sample_login_logs.txt", "r") as file: login_logs = file.readlines() print("Total log entries:", len(login_logs))

How this works: open() opens the text file. readlines() reads each line into a list so your program can scan it with a loop.

Task 3 - Create helper functions

Functions

Write two small functions. One function extracts the username from a log line. The other function extracts the IP address.

def get_user(log_line): parts = log_line.split() for part in parts: if part.startswith("user="): return part.replace("user=", "") return "unknown" def get_ip(log_line): parts = log_line.split() for part in parts: if part.startswith("ip="): return part.replace("ip=", "") return "unknown"

How this works: split() breaks the line into pieces. The loop checks each piece until it finds the part that starts with user= or ip=.

Task 4 - Count failed login attempts

Analysis

Create a dictionary that counts failed attempts per user.

failed_attempts = {} for log in login_logs: if "result=FAILED" in log: user = get_user(log) if user not in failed_attempts: failed_attempts[user] = 0 failed_attempts[user] += 1 print("Failed attempts by user:") print(failed_attempts)

Indentation reminder: The lines inside the for loop are indented. The lines inside each if statement are indented again.

Task 5 - Flag suspicious accounts

Detection

Flag any user with 4 or more failed login attempts.

suspicious_users = [] for user in failed_attempts: if failed_attempts[user] >= 4: suspicious_users.append(user) print("Suspicious users:") print(suspicious_users)

This is a simple rule-based detection. In real cybersecurity work, rules like this are used as a starting point for investigation.

Task 6 - Print the final security report

Report

Finish by printing a readable report.

print() print("SECURITY LOG REPORT") print("-------------------") print("Total log entries:", len(login_logs)) print("Users with failed logins:", len(failed_attempts)) print() for user in failed_attempts: print(user, "had", failed_attempts[user], "failed login attempts") print() if len(suspicious_users) > 0: print("Accounts to review:") for user in suspicious_users: print("-", user) else: print("No suspicious accounts found.")

Expected key findings: bob and dana should be flagged for review.
