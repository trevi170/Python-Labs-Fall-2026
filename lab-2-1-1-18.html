Task 1 - Understand print() parameters

Context

What you'll learn: The print() function has two powerful optional parameters: sep and end.

  • sep - Changes the separator between arguments (default: space)
  • end - Changes what appears at the end of output (default: newline)

Task 3 - Exercise 1: Using sep parameter

Experiment

Write Python code that uses the sep parameter:

  • Print three words using the default separator (space)
  • Print the same three words using sep="***"
  • Print the same three words using sep="..."
  • Take a screenshot of your code and output
print("Programming", "Essentials", "in Python") print("Programming", "Essentials", "in Python", sep="***") print("Programming", "Essentials", "in Python", sep="...")

Expected output:

Programming Essentials in Python Programming***Essentials***in Python Programming...Essentials...in Python
Notice how the separator changes between the words in each line.

Task 4 - Exercise 2: Using end parameter

Experiment

Write Python code that uses the end parameter:

  • Print a line with default end parameter
  • Print a line with end="***"
  • Print a line with end=""
  • Print another line immediately after (to see the effect)
  • Take a screenshot showing all outputs
print("Line 1") print("Line 2", end="***") print("Line 3", end="") print("Line 4")

Expected output:

Line 1 Line 2***Line 3Line 4
Notice how the end parameter changes what appears after each line. When end="", the next print continues on the same line.

Task 5 - Exercise 3: Combining sep and end

Experiment

Write Python code that combines both sep and end parameters:

  • Use both parameters together in the same print() statement
  • Experiment with different combinations
  • Observe how they work together
  • Take a screenshot of your code and output
print("A", "B", "C", sep="-", end="!") print() print("1", "2", "3", sep="|", end="***")

Expected output:

A-B-C! 1|2|3***
Both parameters can be used in the same print() statement for more control over output formatting. The sep parameter affects how arguments are joined, while end controls what appears at the end.
