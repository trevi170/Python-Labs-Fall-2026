🎯 Tasks

Complete each task, then click 📷 Attach screenshot to add a picture of your console output. When all tasks are done, generate the PDF at the bottom and upload it to Blackboard.

Task 1 — Print "Hello, Python!"

Use print() to print the line Hello, Python! using double quotes:

print("Hello, Python!")

Task 2 — Print your first name

Add a second line that prints your own first name in double quotes:

print("Hello, Python!")
print("Alice")   # replace with your name

Task 3 — Break it on purpose 🧨

Remove the double quotes from your name, run the code, and screenshot the error:

print(Alice)

Expected result: NameError: name 'Alice' is not defined
