Lab Overview

In this lab, you'll practice Python's print() function. You'll print simple text, use quotation marks correctly, and learn how Python reacts when text is typed like a variable name.

Learning Objectives

By the end of this lesson, you should be able to:

  • Use print() to display text in the console.
  • Write string values with quotation marks.
  • Recognize the difference between text strings and variable names.
  • Read a simple Python error message and identify what caused it.

Lesson Explanation

The print() function displays output in the console. Text must be written inside quotation marks, such as "Hello, Python!" or 'Hello, Python!'.

If you write a name without quotes, Python treats it as a variable. If that variable has not been created, Python raises a NameError. That error is useful: it tells you Python understood the word as a name, not as text.

Task 5 - Test a common mistake

Debugging

Now remove the quotes around your name and run the code again. This should create an error.

print(Alice)

Expected result: Python should show a NameError because Alice is being treated like a variable name.

Why this happens: print("Alice") prints text. print(Alice) looks for a variable named Alice. If that variable does not exist, Python reports an error.
