Experiment with Python code to learn about escape sequences, string multiplication, and the print() function. Discover how these features can be used to format output creatively.

📋 Lab Overview

In this lab, you'll experiment with existing Python code and make modifications to understand how escape sequences (like \n), string multiplication, and the print() function work together. You'll also discover what happens when you break the rules and fix syntax errors.

✅ Upon completion, you will be able to:

  • Use escape sequences like \n to create multi-line output
  • Multiply strings to repeat them
  • Minimize the number of print() function calls
  • Understand how quotes and syntax affect Python code
  • Discover and fix basic syntax errors
