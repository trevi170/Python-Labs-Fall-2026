Lab Overview

In this lab, you'll experiment with existing Python code and make modifications to understand how escape sequences (like \n), string multiplication, and the print() function work together. You'll also discover what happens when you break the rules and fix syntax errors.

Learning Objectives

By the end of this lesson, you should be able to:

  • Use escape sequences like \n to create multi-line output
  • Multiply strings to repeat them
  • Minimize the number of print() function calls
  • Understand how quotes and syntax affect Python code
  • Discover and fix basic syntax errors

Task 3 - Exercise 1: Minimize print() calls

Experiment

Modify the code to use fewer print() statements by using the \n escape sequence:

  • Start with the starter code below (8 print statements)
  • Combine them into ONE print() statement using \n
  • The output should look identical, but with only one function call

Starter code:

print(" *") print(" * *") print(" * *") print(" * *") print("*** ***") print(" * *") print(" * *") print(" *****")

Rewrite as: (one line with \n between each)

print(" *\n * *\n * *\n * *\n*** ***\n * *\n * *\n *****")

Expected output:

* * * * * * * *** *** * * * * *****
Copy each line of text into your combined print statement, and add \n between them to create newlines.

Task 4 - Exercise 2: Modify the pattern

Experiment

Now that you've minimized print() calls, try modifying the pattern:

  • Make it taller by adding more lines to the top
  • Or use string multiplication to double the width: line * 2
  • Combine your techniques to create something unique

Example: Making it taller

print(" *") print(" * *") print(" * *") print(" * *") print(" * *") print(" * *") print(" * *") print(" * *") print("****** ******") print(" * *") print(" * *")

Expected output (taller):

* * * * * * * * * * * * * * * ****** ****** * * * *

Example: Using string multiplication to double width

print(" * " * 2) print(" * * " * 2) print(" * * " * 2)

Expected output (doubled):

* * * * * * * * * *
String multiplication repeats the entire string. "line" * 2 makes two copies side-by-side.
