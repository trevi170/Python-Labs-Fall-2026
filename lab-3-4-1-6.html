Task 1 - Understand the problem

Context

Scenario: There once was a hat. The hat contained no rabbit, but it did contain a list of five numbers: 1, 2, 3, 4, and 5.

Your task: Modify the existing list named hat_list.

  • replace the middle number in the list with an integer entered by the user
  • remove the last element from the list
  • print the length of the existing list

Key idea: Python lists start counting indexes at 0, so the middle item in [1, 2, 3, 4, 5] is index 2.

What each part does:

  • hat_list = [1, 2, 3, 4, 5]: Creates the starting list.
  • hat_list[2] = ...: Replaces the middle value. Index 2 points to the third item.
  • int(input(...)): Gets a number from the user and converts it to an integer.
  • del hat_list[-1]: Deletes the last item from the list. Index -1 means the final element.
  • print(len(hat_list)): Prints how many elements remain in the list.
