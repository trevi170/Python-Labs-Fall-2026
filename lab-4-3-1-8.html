Task 4 - Plan the day-of-year logic

Guide

The new function is day_of_year(year, month, day). It works by adding the length of every month before the target month, then adding the selected day.

def day_of_year(year, month, day): days = 0 for m in range(1, month): # get days in month m # if month m is invalid, return None # add month m's days to the running total md = days_in_month(year, month) if day >= 1 and day <= md: # return running total plus day else: # return None

What each part does:

  • is_year_leap(year): Returns whether the year is a leap year.
  • days_in_month(year, month): Returns how many days are in a month, or None for invalid input.
  • days = 0: Starts the running total of days.
  • for m in range(1, month): Loops through all months before the target month.
  • md = days_in_month(year, m): Gets the number of days in each previous month.
  • days += md: Adds each previous month's days to the total.
  • md = days_in_month(year, month): Gets the length of the target month.
  • if day >= 1 and day <= md: Checks whether the selected day is valid.
  • return days + day: Returns the final day number in the year.

Loop idea: If the target date is December 31, the loop adds January through November first. Then the function adds day 31 from December.
