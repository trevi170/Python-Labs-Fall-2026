Task 1 - Understand input and output

Context

input() function: Gets text from the user

  • input("Enter your name: ") displays prompt and waits for user to type
  • Returns whatever the user types as a string
  • Must convert to number with float() or int()

print() function: Displays output to the console

  • print("Hello") displays text
  • print(a + b) displays calculation result

Pattern: input → calculate → output
