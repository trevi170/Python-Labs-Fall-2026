Task 4 - Plan the formulas

Guide

The lab gives two conversion facts:

  • 1 American mile = 1609.344 meters
  • 1 American gallon = 3.785411784 liters

Use these facts to convert both the fuel amount and the distance before dividing.

def liters_100km_to_miles_gallon(liters): gallons = liters / 3.785411784 miles = 100 * 1000 / 1609.344 return miles / gallons def miles_gallon_to_liters_100km(miles): # convert miles to units of 100 kilometers # use 3.785411784 liters for one American gallon # return liters per 100 kilometers

What each part does:

  • gallons = liters / 3.785411784: Converts the fuel amount from liters into American gallons.
  • miles = 100 * 1000 / 1609.344: Converts 100 kilometers into miles. First 100 km becomes 100,000 meters, then meters become miles.
  • return miles / gallons: Calculates how many miles can be driven per gallon.
  • km100 = miles * 1609.344 / 1000 / 100: Converts miles into kilometers, then expresses that distance as units of 100 km.
  • litres = 3.785411784: Stores the number of liters in one American gallon.
  • return litres / km100: Calculates how many liters are used for each 100 km.

Why divide at the end? Miles per gallon is distance divided by fuel. Liters per 100 km is fuel divided by distance measured in 100 km units.
