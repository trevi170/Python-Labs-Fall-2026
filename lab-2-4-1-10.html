Task 1 - Understand operators

Context

Arithmetic operators in Python:

  • + = addition
  • - = subtraction
  • * = multiplication (explicit, unlike math notation)
  • / = division (returns float)
  • // = integer division (rounds down)
  • ** = exponentiation (power)
  • % = modulo (remainder)

Key difference: In math, 3x means 3×x. In Python, you must write 3 * x explicitly.
