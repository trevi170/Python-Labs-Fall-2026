Task 1 - Understand the problem

Context

Scenario: A boy and his father are building a flat pyramid-shaped wall with wooden blocks. Each lower layer contains one block more than the layer above it.

Your task: Write a program that reads the number of blocks the builders have and outputs the height of the pyramid that can be built using those blocks.

The height is measured by the number of fully completed layers. If there are not enough blocks to complete the next layer, the builders stop immediately.

  • ask the user to enter the number of blocks
  • use a while loop
  • count only fully completed layers
  • print the height using the required message

Task 3 - Write your code

Code

Starter code:

blocks = int(input("Enter the number of blocks: ")) # # Write your code here. # print("The height of the pyramid:", height)

Complete solution:

💡 Type the solution yourself so you practice while-loop conditions and counters.

What each part does:

  • height = 0: Starts the pyramid with no completed layers.
  • in_layer = 1: The first layer needs one block.
  • while in_layer <= blocks: Continues only if there are enough blocks for the next full layer.
  • height += 1: Counts one completed layer.
  • blocks -= in_layer: Uses the blocks needed for that layer.
  • in_layer += 1: Makes the next layer require one more block.
