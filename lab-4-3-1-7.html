Scenario

Your task is to write and test a function which takes two arguments, a year and a month, and returns the number of days for the given month/year pair. Only February is sensitive to the year value, but your function should be universal.

Think of the function as a small helper that answers one question: for this year and this month, how many days are there? For most months, the answer never changes. January is always 31 days, April is always 30 days, and so on. February is the special case because it has 28 days in a normal year and 29 days in a leap year.

The initial part of the function is ready. Now, convince the function to return None if its arguments don't make sense. Returning None is a way of saying, "I cannot give a real number of days for this input."

Use the previously written and tested function from LAB 4.3.1.6. A list filled with the months' lengths will significantly shorten the code.

Task 1 - Understand the problem

Context

Prerequisite: This lab builds on Lab 4.3.1.6. You will reuse your is_year_leap(year) function.

Scenario: Write and test a function that takes two arguments, a year and a month, and returns the number of days for that month/year pair.

Only February depends on whether the year is a leap year, but the function should work for every month.

  • return None if the year is before 1582
  • return None if the month is less than 1 or greater than 12
  • use a list of month lengths
  • use is_year_leap(year) to handle February in leap years

Why 1582? The Gregorian calendar rules used by this lab begin in 1582. For this exercise, any earlier year should be treated as invalid.

Why return instead of print? The function should not display the answer directly. It should return the answer so the testing code can compare it with the expected result.

Task 4 - Plan the month logic

Guide

Use this structure to build the new function. It uses the leap-year function from the previous lab.

Before the function tries to look up a month, it should reject impossible values. If month is 0 or 13, there is no matching position in the list. If year is before 1582, the lab asks the function to return None.

def is_year_leap(year): if year % 4 != 0: return False elif year % 100 != 0: return True elif year % 400 != 0: return False else: return True def days_in_month(year, month): # if statement # ... days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31] res = days[month - 1] if month == 2 and is_year_leap(year): res = 29 return res test_years = [1900, 2000, 2016, 1987] test_months = [2, 2, 1, 11] test_results = [28, 29, 31, 30] for i in range(len(test_years)): yr = test_years[i] mo = test_months[i] print(yr, mo, "->", end="") result = days_in_month(yr, mo) if result == test_results[i]: print("OK") else: print("Failed")

What each part does:

  • is_year_leap(year): Reuses the function from the previous lab to identify leap years.
  • days_in_month(year, month): Defines a new function with two parameters.
  • if year < 1582 or month < 1 or month > 12: Rejects invalid input by returning None.
  • days = [...] Stores the normal number of days in each month.
  • res = days[month - 1] Looks up the month length using the correct list index.
  • if month == 2 and is_year_leap(year): Checks whether February should have 29 days.
  • return res Sends the number of days back to the testing code.

Index reminder: Months start at 1, but list indexes start at 0. That is why the code uses days[month - 1].

Task 5 - Complete and test the code

Code

Complete the program so invalid arguments return None, February uses the leap-year function, and every test prints OK.

Read the function from top to bottom. First it checks for invalid input. Then it creates the normal month-length list. Next it chooses the correct month using month - 1. Finally, it makes one adjustment: if the month is February and the year is a leap year, it changes the result from 28 to 29.

def is_year_leap(year): if year % 4 != 0: return False elif year % 100 != 0: return True elif year % 400 != 0: return False else: return True def days_in_month(year, month): if year < 1582 or month < 1 or month > 12: return None days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31] res = days[month - 1] if month == 2 and is_year_leap(year): res = 29 return res test_years = [1900, 2000, 2016, 1987] test_months = [2, 2, 1, 11] test_results = [28, 29, 31, 30] for i in range(len(test_years)): yr = test_years[i] mo = test_months[i] print(yr, mo, "->", end="") result = days_in_month(yr, mo) if result == test_results[i]: print("OK") else: print("Failed")

How to read the tests:

  • 1900, 2 means February 1900. It should return 28.
  • 2000, 2 means February 2000. It should return 29.
  • 2016, 1 means January 2016. It should return 31.
